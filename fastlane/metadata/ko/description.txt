두 대의 기기를 무선 원격 카메라 시스템으로 만들어보세요. 인터넷도 WiFi도 계정도 필요 없습니다. 연결하고 바로 촬영하세요.

Remote Shutter는 P2P 기술로 두 대의 기기를 직접 연결합니다. 한 대는 카메라가 되고, 다른 한 대는 라이브 모니터가 있는 리모컨이 됩니다. 단체 사진, 셀카, 삼각대 촬영, 크리에이티브 앵글, 핸즈프리 촬영에 완벽합니다.

새 기능 — Mac 완전 지원
- Mac을 카메라로 사용: 내장, USB, 전문가용 웹캠은 물론 연속성 카메라(Continuity Camera)로 iPhone까지
- Mac에 연결된 모든 카메라를 iPhone에서 실시간으로 전환
- 반대로도 가능: Mac의 큰 화면을 iPhone 카메라의 디렉터 모니터로 사용

기능
- Apple Watch로 손목에서 셔터 제어
- 선명한 후면 카메라로 셀카와 단체 사진 — 리모컨의 실시간 미리보기로 구도 확인
- 최대 15미터 거리에서 무선 셔터 제어
- 리모컨 기기에서 카메라 실시간 미리보기
- 카메라 원격 전환 — iPhone은 전면/후면, Mac은 연결된 모든 카메라
- 카메라 플래시 제어
- 조절 가능한 촬영 타이머
- 원격 동영상 촬영
- iPhone, iPad, Mac에서 사용 가능
- 인터넷이나 WiFi 불필요 — 기기 간 직접 연결

사용 방법
1. 두 대의 기기에서 Remote Shutter 실행
2. P2P로 자동 연결
3. 카메라와 리모컨 역할 선택
4. 어디서든 촬영 시작!

Mac에 연결한 전문가용 카메라로 제품을 촬영하든, 큰 화면으로 연출을 확인하든, 가족사진을 준비하든, Remote Shutter로 다른 기기에서 카메라를 무선으로 완벽하게 제어하세요.
